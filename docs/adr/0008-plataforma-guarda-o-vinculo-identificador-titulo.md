# A plataforma gera e guarda o vínculo entre Identificador de cobrança e Título

O Protheus é só leitura (ADR 0002), então o txid e o nosso número das Cobranças identificadas são gerados pela plataforma e o vínculo com o Título fica no armazenamento dela; para emitir sai só o mínimo: Título, valor, vencimento e CNPJ do Franqueado. Título que já tem nosso número no Protheus mantém esse boleto e ganha só o Pix, para nenhum Título ter dois boletos registrados. O Identificador de cobrança leva o Crédito direto ao Título, mas não dispensa as regras de valor: valor exato ou dentro do Encargo vai para a Lista de baixa, o resto vai para a Fila de exceções, como o nosso número na fase 1. Pagar uma Cobrança identificada também não cria Pagador conhecido; só a confirmação da Analista cria.
