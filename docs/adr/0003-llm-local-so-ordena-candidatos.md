# LLM local só dá parecer sobre o nome e nunca alimenta a Lista de baixa

Nenhum dado sai do ambiente do cliente, então a LLM roda local via Ollama (MacBook Air M2 8 GB no desenvolvimento, servidor do cliente em produção), o que limita o modelo a ~3-4B quantizado. Ela só é chamada quando o nome do Extrato não é Nome por prefixo de nenhum nome do Franqueado candidato já filtrado por regra (abreviação, palavras invertidas, palavras faltando), e responde se o nome é daquele Franqueado e por quê. Tudo que passa por ela vai para a Fila de exceções com esse parecer; se ela negar, o motivo passa a ser sem identificação do pagador, e se o Ollama estiver fora, o item vai sem parecer, marcado como IA indisponível. A confirmação da Analista vira Pagador conhecido, e o caso passa a ser resolvido por regra nas importações seguintes.
